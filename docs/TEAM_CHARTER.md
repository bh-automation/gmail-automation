# Fachteam / Engineering Charter

## Principal Architect
Owns boundaries, data flow, staged privilege and ADRs.

## Gmail/API Engineer
Owns OAuth profiles, Gmail search, message/thread semantics, labels, drafts, retry behavior and quotas.

## Security & IAM Engineer
Owns scope minimization, secrets, capability policy, token handling and abuse cases.

## Privacy Engineer
Owns data minimization, logging/redaction, retention and local-data handling.

## AI Safety / Classification Engineer
Owns rule quality, confidence thresholds, prompt-injection isolation and optional LLM contract.

## QA / Reliability Engineer
Owns fixtures, idempotency, concurrency, recovery, rate-limit and Windows-specific tests.

## Red Team A
Attacks security/product invariants.

## Red Team B
Attacks operations/reliability/recovery.

## UX / Fluent Engineer
Owns clear status, hierarchy, safe action affordances, accessibility and operator confidence.

## DevEx / Release Engineer
Owns Git, CI, reproducible setup, versioning, release gates and signed artifacts.
